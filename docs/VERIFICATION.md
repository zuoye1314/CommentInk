## 继续开发时的验收重点

- 插入公式/图表、应用、撤销、保存、重新打开、完整退出重启；普通预览不得修改源文件。
- 光标进入显示源码、离开恢复预览；保持原位置，并分别核对多个窗口和多光标。
- C 有星/无星块注释、空格/Tab/CRLF；非法标记前缀须定位提示。
- Python `#` 及带完整标记的普通/r/u 三引号载体；三引号仍为字符串，新建和复制默认 `#`，拒绝 f/bytes 等未支持形式。
- 复制到另一文件后可恢复编辑；旧版本和损坏数据不被静默覆盖。
- 草稿恢复、只读、文件/目录重命名、并发修改和取消保护。
- 真正原生编辑器中的 SVG 加载、切片对齐、滚动、换行、缩放和空间不足回退。Webview 预览不算此项通过。
- 离线字体/工作线程/截图资源随包可用；大输入和异常渲染有限时/限量保护。

Windows、macOS、Remote/Web、任意字体与缩放、中文输入法、读屏和长期性能尚未完成同等验收。记录环境、步骤、预期、实际结果及证据；没有运行的用例标“未验证”。
