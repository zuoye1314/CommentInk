# CommentInk 设计约定

用户要求每次相关设计先读本文件；入口见根目录 AGENTS.md。新会话或上下文压缩后继续设计时重新读取。此文件为原工作区设计约定在独立源码仓库中的整理版，不把历史截图或说明冒充本轮实测。

界面与交互先读 [使用指南](../../INSTALL.md)，查看真实 `studio/editor.*` 源码；架构、存储和编辑器集成先读 [开发指南](../../docs/DEVELOPMENT.md)，制定测试或评审先读 [验证范围](../../docs/VERIFICATION.md)。

## 已确定的产品原则

- 以 ASCIIFlow 的简洁为参考：画布为主、紧凑工具栏、属性与模板按需展开。图形创作和可视化公式模板是主路径，不要求学习图表语言、JSON 或 TeX；复杂 TeX 是可选入口。
- 显示名 CommentInk；发布者 `zuoye`、内部名 `comment-preview-probe`、现有命令及草稿身份保持。常用操作集中在编辑器右键 CommentInk 子菜单。
- 源码为唯一权威，保存带版本的结构和原始 TeX、对象坐标、稳定标识及关联；SVG、缓存和视口可重建。复制/关闭重开后能继续编辑，不依赖原机临时状态。
- 紧凑可读 JSON 约 120 字符一行。真实正文行数取数据所需与预览所需的最大值；仅插入、应用、复制或明确整理时补最少空白注释行。查看、滚动、缩放绝不写文件。用户删行导致空间不足时保留源码并提示缺少几行，不能擅自补回。
- 原位显示依赖现有代码行与稳定 decoration API，不能宣称任意高度自动撑开。不得注入工作台 DOM 或借用私有 Monaco API；Webview/悬停/侧边不能作为原生原位显示的证据。
- 光标/选区进入对象恢复源码，全部离开自动渲染；按文件及窗口隔离，异步过期结果不能覆盖新状态。手动整窗口源码模式保留到明确恢复。自动切换不改源文、移动光标或滚动。
- 注释旁不常驻“编辑公式/图表”“原位预览”“查看源码”按钮。应用后就近返回原对象，保留上下普通文字与块外光标，不跳文件底部。
- 注释识别先判断宿主语法。C 块中零前缀、空格、Tab、可选重复装饰星号有效；数字或说明文字前缀须定位诊断，不能当注释包装剥离。正文中的乘号、字符串及转义不得清洗。
- 常见语言按本地语言语法/配置适配，不把 C 前缀白名单当通用规则。JSON 不支持注释，JSONC 可支持；未知/混合语法保守回退并说明。
- Python 三引号是字符串扩展，默认只识别完整独占标记的普通/r/u 三引号和 docstring，读取源文拼写而不执行 Python。普通字符串、f/bytes 不纳入；新建/复制默认 `#`，应用须提示更新字符串内容并保留引号、缩进和前后代码。
- 方程模板提供分式、根号、上下标、积分、求和、矩阵及嵌套；原始 TeX 不得静默转换丢失。排版测量后确定节点边界；保留手动布局，碰撞只提示或显式整理。
- 平移/缩放与模型分离；拖拽一次撤销，Esc 可取消；输入框拥有自身键盘输入与撤销。连线端点与标签几何应在画布及渲染共用。
- 草稿与提交分离。只读、重命名、并发改动和取消必须保护原数据；提交前后验证实际文档结果，不能只信编辑 API 返回值。失败保留可恢复内容。
- 离线渲染、资源随包。输入和 Webview 消息均不可信，限制尺寸与耗时，不执行源文件、TeX 外部命令或远程资源。

## 交付与验证

按任务规模说明变化、依赖能力、验证环境/步骤/结果及剩余限制。明确区分设计目标、已验证能力与未验证假设。覆盖原生编辑器真实图片加载和布局，不能仅核对 SVG 字符串或装饰数量。只做相关必要测试，不为小改动机械重跑全部矩阵。

使用指南面向新手、含真实 VS Code 截图、支持离线阅读，不加入版本更新流水账。维护 INSTALL.md，打包脚本生成 docs/USER-GUIDE.md；本地图片通过不代表 Marketplace CDN 已可访问。
